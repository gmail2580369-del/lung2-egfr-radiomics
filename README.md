\# Lung2 EGFR Radiomics



CT radiomics study for prediction of EGFR mutation status in NSCLC.



\## Project status



Analysis in progress.



\## Project structure



\- `notebooks/`: Jupyter notebooks for analysis and exploration

\- `src/`: Python source code

\- `config/`: analysis and PyRadiomics configuration files

\- `data/`: local research data

\- `results/`: model predictions, metrics, selected features, and figures

\- `manuscript/`: manuscript-related files



\## Data



Imaging and clinical data are stored locally and are not included in this repository.
